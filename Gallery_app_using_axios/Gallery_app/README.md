# 📸 Gallery App using Axios

A responsive image gallery application built with **React**, **Vite**, **Axios**, and **Tailwind CSS**. Fetches random images from the Picsum.photos API with pagination support.

## ✨ Features

- 🖼️ **Dynamic Image Gallery** - Displays 10 random images per page
- 🔄 **Pagination** - Navigate through different pages of images
- 📱 **Responsive Design** - Works seamlessly on mobile, tablet, and desktop
- ⚡ **Fast Loading** - Built with Vite for optimized performance
- 🎨 **Modern UI** - Styled with Tailwind CSS

## 🛠️ Tech Stack

- **React** 19.2.6 - UI library
- **Vite** 8.0.12 - Build tool & dev server
- **Axios** 1.16.1 - HTTP client
- **Tailwind CSS** 4.3.0 - Utility-first CSS framework

## 📦 Installation

1. Clone or navigate to the project directory:
```bash
cd Gallery_app
```

2. Install dependencies:
```bash
npm install
```

## 🚀 Development

Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## 🏗️ Build

Create an optimized production build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## 📝 Linting

Run ESLint to check code quality:
```bash
npm run lint
```

## 🎯 How It Works

1. Fetches images from [Picsum.photos API](https://picsum.photos/)
2. Displays 10 images per page in a responsive grid
3. Users can navigate between pages using Previous/Next buttons
4. Each image shows the photographer's name
5. Clicking on an image opens it in a new tab

## 📱 Layout

- **Mobile**: 1 column grid
- **Tablet**: 3 columns
- **Desktop**: 5 columns
